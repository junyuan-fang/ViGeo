# 第 2 章 旋转为什么是"弯的"：SO(3)、四元数、李群

[← 上一章](01_manifold_basics.md) · [目录](README.md) · [下一章：流形上的曲线 →](03_curves_on_manifolds.md)

> 本章目标：把第 1 章的概念落到**相机旋转**上。读完你应该能看懂代码里的 `so3_log` 和 `R1ᵀ R2` 为什么这么写。

---

## 2.1 旋转矩阵：9 个数，只有 3 个自由度

一个 3D 旋转可以写成 3×3 矩阵 R，满足两个条件：

- $R^\top R = I$（不改变长度和角度）
- $\det R = 1$（不做镜像）

所有这样的矩阵放在一起，叫 **SO(3)**（3 维特殊正交群）。
R 有 9 个数，但上面两个条件把它约束得只剩 **3 个自由度**（绕哪个轴转，2 个；转多少度，1 个）。
所以 SO(3) 是 9 维空间里的一个 **3 维曲面**，也就是一个流形。

---

## 2.2 为什么说它是"弯的"：三个小实验

**实验 1：取平均会出错。** 绕 z 轴转 0° 和转 180° 的两个旋转矩阵，直接取平均：

```
R₁ = diag(1, 1, 1),  R₂ = diag(-1, -1, 1)   →   (R₁+R₂)/2 = diag(0, 0, 1)
```

结果的行列式为 0，**根本不是旋转**。两个旋转矩阵的"中点"跑出了 SO(3)，就像地球表面两点连线的中点跑进了地心。

**实验 2：转一圈回到原点。** 绕同一个轴一直转，360° 后回到起点。这和圆一样，是"绕回来"的空间，不像直线那样无限延伸。

**实验 3：顺序有关。** 先绕 x 转 90° 再绕 y 转 90°，和反过来做，结果不同（拿手机试一下）。平直空间里的加法是不分顺序的，旋转的复合不是。

**结论**：旋转不能当成普通向量来加减、取平均、求差，必须用第 1 章的 Log / 测地距离。

---

## 2.3 轴角表示：旋转空间的"切空间"

任何一个旋转都可以说成："绕单位轴 n 转 θ 角"。把两者合成一个 3 维向量：

$$\omega = \theta \cdot n \in \mathbb{R}^3$$

这个 ω 叫**轴角向量**（axis-angle / rotation vector）：方向是转轴，长度是转角。

**ω 正好就是第 1 章的 Log**：站在"不转"（单位矩阵 I）这一点，看旋转 R，得到切空间里的向量 ω。

- $\mathrm{Log}(R) = \omega$：旋转矩阵 → 轴角向量
- $\mathrm{Exp}(\omega) = R$：轴角向量 → 旋转矩阵（就是 Rodrigues 公式，也等于矩阵指数 `expm`）

单位元处的切空间有个专门的名字：**李代数** so(3)。它就是 ℝ³，可以随便加减。

---

## 2.4 李群：任何一点都能"搬回"原点

SO(3) 不只是个流形，它还是一个**群**：两个旋转可以复合（矩阵乘法），每个旋转都有逆（转置）。既是流形又是群的东西叫**李群**（Lie group）。

李群最大的好处是：**不需要每个点都单独定义切空间，全部搬回单位元就行**。

问："站在 R₁ 看 R₂，差了多少？"
答：先把 R₁ "撤销"掉，看剩下的部分：

$$R_1^\top R_2 \quad\text{（从 } R_1 \text{ 到 } R_2 \text{ 还要再转多少）}$$

这是一个旋转，对它取 Log 就得到轴角向量，长度就是两者相差的角度：

$$d(R_1, R_2) = \lVert \mathrm{Log}(R_1^\top R_2) \rVert \in [0, \pi]$$

这就是**旋转的测地距离**：两个朝向之间相差的那个角度。代码：

```python
# src/loss/riemannian.py
def so3_geodesic_angle(R1, R2):
    return so3_log(R1.transpose(-1, -2) @ R2).norm(dim=-1)   # ‖Log(R1ᵀ R2)‖
```

> **度量是"双不变"的**：给 R₁、R₂ 同时左乘或同时右乘同一个旋转，距离不变。
> 直观上，"两个相机朝向差几度"不应该取决于你把世界坐标系放在哪。第 3 章会用到这个性质。

---

## 2.5 四元数：网络实际输出的东西

ViGeo 的 camera head 输出的不是旋转矩阵，而是**四元数** q = (x, y, z, w)，4 个数。和轴角的关系：

$$q = (\, n \sin\tfrac{\theta}{2},\ \cos\tfrac{\theta}{2} \,)$$

单位四元数构成 4 维空间里的单位球面 S³。有一个关键细节：**q 和 −q 表示同一个旋转**。
（θ 换成 θ+360°，sin 和 cos 的半角都会变号，但旋转本身没变。）

### 原 loss 的三个问题

原来的 `camera_loss` 对四元数做 `|q_pred − q_gt|` 的 L1，然后取平均：

1. **算的是"弦"不是"弧"**：在 S³ 上直接相减，就是第 1 章那个"穿隧道"的距离。
2. **和转轴有关**：L1 范数对坐标轴方向敏感，同样差 30°，绕 x 轴和绕对角线轴算出来的 L1 不一样（第 5 章图 1 的橙色带）。
3. **符号跳变**：为了处理 q 和 −q 的歧义，代码强制 w ≥ 0（`standardize_quaternion`）。当 w 在 0 附近时，预测稍微一动，q 就整个翻号，L1 从 ~0 跳到 ~2。

### 从四元数算角度：`so3_log` 逐行

```python
def so3_log(R, eps=1e-12):
    quat = mat_to_quat(R)                        # 旋转矩阵 → 四元数 (x,y,z,w)，已保证 w ≥ 0
    v, w = quat[..., :3], quat[..., 3]           # v = n·sin(θ/2)，w = cos(θ/2)
    v_norm = torch.sqrt(v.square().sum(-1) + eps)  # |v| = sin(θ/2)，加 eps 防止除 0
    theta = 2.0 * torch.atan2(v_norm, w)         # θ = 2·atan2(sin(θ/2), cos(θ/2))
    return v * (theta / v_norm)[..., None]       # ω = θ · n = θ · v/|v|
```

**为什么用 atan2 而不是 acos(w)？** 两者数学上相等，但 $\frac{d}{dx}\arccos x = -\frac{1}{\sqrt{1-x^2}}$，在 x→1（角度→0，也就是预测接近真值）时**梯度趋于无穷**，训练会炸。atan2 没有这个问题。

**这里 w ≥ 0 的跳变为什么不伤害我们？** 因为我们只对**相对旋转** $R_1^\top R_2$ 取 Log。只要两个旋转相差不到 180°，相对旋转的 w 就离 0 很远。相邻帧之间的转动通常只有几度。

## 2.6 加上平移：SE(3) 与相对位姿

相机位姿 = 旋转 R + 位置 t，写成 4×4 矩阵：

$$T = \begin{bmatrix} R & t \\ 0 & 1 \end{bmatrix} \in SE(3)$$

ViGeo 里 T 是 **camera-to-world**：把相机坐标系里的点变到世界坐标系。

### 相对位姿：从第 i 帧到第 i+1 帧怎么动的

和 2.4 的思路一样，"站在 T_i 看 T_{i+1}" = $T_i^{-1} T_{i+1}$。展开：

$$T_i^{-1} T_{i+1} = \begin{bmatrix} R_i^\top R_{i+1} & R_i^\top (t_{i+1} - t_i) \\ 0 & 1 \end{bmatrix}$$

- 旋转部分 $R_i^\top R_{i+1}$：这一步相机**转了多少**
- 平移部分 $R_i^\top (t_{i+1} - t_i)$：这一步相机**走了多远**，而且是用**第 i 帧相机自己的坐标系**表达的（"往前 1 米、往右 0.2 米"），称为 **body frame**。

```python
# src/loss/riemannian.py :: relative_twist
R_prev_T = R[:-1].transpose(-1, -2)                      # R_iᵀ，对所有 i 一次算完
omega = so3_log(R_prev_T @ R[1:])                         # Log(R_iᵀ R_{i+1})：转了多少
v = torch.einsum('sij,sj->si', R_prev_T, t[1:] - t[:-1])  # R_iᵀ (t_{i+1} − t_i)：走了多远
```

### 为什么用 body frame：对"整体搬家"免疫

假设整条预测轨迹完美，只是整体被一个刚体变换 G 挪了位置（换了世界坐标系）。那么：

$$(G T_i)^{-1}(G T_{i+1}) = T_i^{-1} G^{-1} G\, T_{i+1} = T_i^{-1} T_{i+1}$$

**G 被消掉了**，相对位姿完全不变。所以基于相对位姿的 loss 只关心轨迹的"形状"，不关心它被放在世界的哪里。这个性质叫 **gauge 不变性**。

### 我们用的度量

旋转和平移的单位不同（弧度 vs 米），需要一个权重 λ 把它们合起来：

$$\text{误差} = \underbrace{\text{旋转角度差}}_{\text{测地距离}} + \lambda \cdot \underbrace{\lvert \text{平移差} \rvert_1}_{\text{body frame}}$$

代码里 λ 是 `trans_weight`，默认 1；平移用 L1 并 `clamp(max=100)`，和原 loss 保持一致，这样新旧 loss 的量级可比。
（严格地说，这是 SO(3)×ℝ³ 上的"积度量"。SE(3) 还有把旋转和平移耦合起来的度量，第 6 章列为扩展方向。）

## 2.7 本章小结

| 概念 | 一句话 | 代码 |
|---|---|---|
| SO(3) | 所有 3D 旋转，3 维的弯曲流形 | 3×3 矩阵 R |
| 轴角 ω = θn | 旋转的 Log，住在切空间（李代数）ℝ³ 里 | `so3_log` 的输出 |
| 李群 | 既是群又是流形；任意两点的差可以搬回原点比较 | `R1ᵀ @ R2` |
| 测地距离 | 两个朝向相差的角度 | `so3_geodesic_angle` |
| 四元数 | 网络输出；q 与 −q 等价，导致符号跳变 | `mat_to_quat` |
| SE(3) | 旋转 + 平移 | 4×4 或 3×4 矩阵 |
| 相对位姿 | $T_i^{-1}T_{i+1}$，对整体搬家不变 | `relative_twist` |

**带走一句话**：比较两个旋转，就看 $R_1^\top R_2$ 转了多少度。比较两段运动，就看各自的 $T_i^{-1}T_{i+1}$。

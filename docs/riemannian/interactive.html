建议的操作顺序

1. 抖动调到 0，只拉"整体偏移"：0 阶上升，1 阶和 2 阶保持为 0。原因是它们只看相邻帧之间的相对运动 T_i⁻¹T_{i+1}，对整体刚体变换不变。

2. 只拉"每帧抖动"：2 阶反应最强。视频几何里的"闪烁 / 不一致"在相机上就表现为这种误差。

3. 只拉"速度漂移"：0 阶随时间累积变大，1 阶给出恒定信号，2 阶几乎为 0。

4. 切到"打乱"：平滑先验在 GT 自己身上就爆掉了，而匹配式损失基本不变。这就是本分支只用匹配式损失的原因。
